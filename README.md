# Rizkyy — iPhone Store

Website katalog iPhone seri 8–15 yang siap dipublikasikan lewat GitHub Pages.

## Fitur
- Desain responsif desktop dan mobile.
- Katalog produk dibuat otomatis dengan JavaScript.
- Tombol WhatsApp dengan pesan awal otomatis untuk setiap seri.
- Menu navigasi mobile, FAQ, bagian tentang, dan tombol WhatsApp mengambang.

## Catatan penting
Harga pada kartu hanya contoh tampilan. Ubah harga, deskripsi, atau daftar seri di array `products` dalam `script.js` agar sesuai stok sebenarnya. Jangan mengklaim produk original/garansi jika belum dapat dipastikan.

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`, `style.css`, dan `script.js` ke root repository.
3. Klik **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses deploy, lalu buka alamat GitHub Pages yang ditampilkan.
